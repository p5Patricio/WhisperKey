¿Cómo empezar a usarlo?

Sin configuraciones complejas ni terminales.

1

Descargá el instalador

Descargá el archivo WhisperKey-Setup.exe (~28 MB) desde la sección de descargas.

2

Seguí el Onboarding

El asistente detectará automáticamente tu hardware (GPU NVIDIA o CPU) y descargará el modelo óptimo.

3

Presioná F9 y hablá

Colocá el cursor en cualquier aplicación, mantené presionado F9 y soltalo para transcribir al instante.
